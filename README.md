# Shaory - Triple Espresso

## Descripción del proyecto

**Shaory - Triple Espresso** es una landing page moderna desarrollada para la cafetería de especialidad _Triple Peaks Café_. La página fue diseñada para ofrecer a los clientes una experiencia intuitiva donde consultar el concepto de la cafetería, horarios, ubicación y realizar la reserva de una mesa en línea.

### Tecnologías utilizadas

- **HTML5**: Estructuración semántica y accesible del contenido (`<header>`, `<main>`, `<section>`, `<form>`, `<footer>`).
- **CSS3**: Estilizado visual utilizando la arquitectura y metodología **BEM** (Block, Element, Modifier) para mantener un código limpio, modular y mantenible.
- **Flexbox**: Maquetación y alineación flexible de elementos en el encabezado, formulario y pie de página.
- **Normalize.css**: Normalización de los estilos base para garantizar consistencia entre diferentes navegadores.
- **Google Fonts**: Integración de las fuentes _Inter_ y _Noto Serif_ para lograr una jerarquía tipográfica limpia.

## Planes de mejora

- **Validación e interactividad con JavaScript:** Agregar lógica en JS para procesar las reservas en tiempo real, validar dinámicamente las fechas/horarios disponibles y desplegar una ventana modal de confirmación al usuario.
- **Diseño adaptativo (Responsive Design):** Incorporar _media queries_ para optimizar la visualización y experiencia de usuario en dispositivos móviles y tablets.
- **Modo Oscuro (Dark Theme):** Implementar un conmutador de tema claro/oscuro que guarde la preferencia del usuario.
